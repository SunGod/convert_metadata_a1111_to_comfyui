# convert_metadata_a1111_to_comfyui
A handy little Python script that converts the A1111 metadata stored in a PNG image file and converts it all into ComfyUI-friendly metadata format. Many awesome ComfyUI image library management tools don't read A1111 metadata, so this little gem will help bridge that gap, and make those tools treat A1111 images like they were made in ComfyUI.
